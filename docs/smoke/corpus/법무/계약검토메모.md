# 표준 계약서 검토 메모

## 검토 배경

법무팀은 신규 협력사와의 용역계약 표준양식을 갱신했다. 기존 양식이 손해배상 상한
조항을 명시하지 않아 분쟁 시 해석이 갈릴 수 있다는 지적이 있었다.

## 주요 변경 사항

- 손해배상 상한: 계약금액의 100%로 명시
- 비밀유지 기간: 계약 종료 후 3년으로 통일
- 관할 법원: 서울중앙지방법원으로 고정

## 적용 대상

이번 표준양식은 신규 체결 계약부터 적용하며, 기존 계약은 갱신 시점에 순차 반영한다.
소급 적용은 하지 않는다.

## 후속 조치

각 부서는 외부 업체와 계약을 체결할 때 법무팀 검토를 반드시 거쳐야 하며, 검토 없이
서명된 계약은 효력을 인정하지 않는다.
