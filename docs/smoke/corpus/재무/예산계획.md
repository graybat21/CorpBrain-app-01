# 2026년도 예산계획

## 배경

재무팀은 2025년 실적을 바탕으로 2026년도 전사 예산을 편성했다. 연구개발 인력 확충과
클라우드 인프라 비용 증가를 반영해 전년 대비 예산 총액을 18% 늘렸다.

## 부문별 배정

| 부문 | 배정액 | 전년 대비 |
|---|---|---|
| 인건비 | 42억원 | +22% |
| 연구개발 | 15억원 | +30% |
| 마케팅 | 8억원 | +5% |
| 일반관리비 | 6억원 | +3% |

## 집행 원칙

부문별 배정액의 분기별 집행 현황은 지출보고.md 에서 확인한다. 예산 대비 집행률이
분기 중 80%를 넘으면 재무팀에 사전 협의를 거쳐야 추가 집행이 가능하다.

## 승인 절차

50만원 이상의 지출은 회계정책.md 가 정한 결재 라인을 따른다. 예산 편성 자체의 변경은
경영진 승인이 필요하며, 재무팀 예산 담당자가 변경 이력을 관리한다.
