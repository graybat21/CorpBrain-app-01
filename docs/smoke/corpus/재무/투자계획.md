# 2026년 신규 투자 계획

## 배경

원가분석.md 가 지적한 클라우드 인프라 비용 증가 추세에 대응하고, 예산계획.md 가
배정한 연구개발 예산 15억원 중 일부를 온프레미스 GPU 서버 도입에 쓰기로 했다.

## 투자 항목

- GPU 서버 2대 도입: 4억원 (3분기 집행 예정)
- 사무공간 확장(연구개발파트 증원 대응): 2억원
- 보안 솔루션 갱신: 5천만원

## 회수 기준

GPU 서버 도입은 18개월 내 클라우드 비용 절감분으로 투자금을 회수하는 것을 목표로
한다. 재무팀은 분기마다 회수 진행률을 지출보고.md 형식과 동일하게 별도 보고한다.

## 승인 상태

경영진 1차 승인을 받았으며, 최종 집행은 5월 이사회에서 확정한다.
