# 2026년 상반기 마케팅 캠페인 기획

## 배경

마케팅팀은 신규 기능 출시에 맞춰 상반기 통합 캠페인을 기획한다. 예산계획.md 가 배정한
마케팅 예산 8억원 중 3억원을 이번 캠페인에 집중 배정했다.

## 캠페인 구성

- 티저 단계(4주): 브랜드 인지도 제고, 소셜미디어 중심
- 본 캠페인(6주): 기능 소개 콘텐츠, 웨비나 2회
- 리텐션 단계(4주): 기존 고객 대상 리마케팅

세부 채널별 운영 방안은 소셜미디어전략.md 에서 다루고, 톤앤매너는 브랜드가이드.md 를
따른다.

## 목표 지표

- 신규 리드 확보: 1,200건
- 웨비나 참석: 회당 200명 이상
- 브랜드 검색량: 전분기 대비 40% 증가

## 담당

마케팅팀 캠페인 담당자가 전체 일정을 총괄하며, 채널별 실무는 파트너십제휴.md 에 정리된
외부 대행사와 공동 진행한다.
