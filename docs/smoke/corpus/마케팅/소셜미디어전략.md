# 소셜미디어 운영 전략

## 목적

캠페인기획.md 의 티저·본 캠페인 단계에 맞춰 채널별 콘텐츠 전략을 구체화한다.

## 채널별 방향

- 인스타그램: 제품 스크린샷 중심 카드뉴스, 주 3회 발행
- 유튜브: 기능 소개 숏폼, 캠페인기획.md 의 웨비나 하이라이트 클립 재활용
- 링크드인: B2B 의사결정권자 대상 사례 콘텐츠

## 운영 원칙

브랜드가이드.md 가 정한 색상·로고 규정을 모든 채널에서 일관 적용한다. 콘텐츠 발행
전 최종 검수는 마케팅팀 채널 담당자가 맡는다.

## 성과 측정

채널별 도달·참여율을 주간 단위로 취합해 고객설문분석.md 의 반응 데이터와 함께
캠페인 중간 점검 회의에서 공유한다.
