# 고객 설문 분석 결과

## 조사 개요

캠페인기획.md 의 티저 단계 종료 시점에 기존 고객 320명을 대상으로 만족도 설문을
진행했다. 응답률은 42%였다.

## 주요 결과

- 제품 만족도: 5점 만점 중 4.1점
- 재구매 의향: 78%
- 추천 의향(NPS): +32

소셜미디어전략.md 를 통해 유입된 응답자군이 다른 채널 유입군보다 만족도가 0.3점 높게
나타나, 해당 채널의 메시지가 실제 제품 경험과 잘 맞는다는 신호로 해석된다.

## 개선 요청 상위 항목

1. 검색 속도 개선 (응답자의 34%)
2. 모바일 대응 (응답자의 21%)
3. 문서 정리 자동화 고도화 (응답자의 18%)

## 활용 계획

이 결과는 다음 캠페인 메시지 방향 설정과 제품팀 우선순위 논의에 함께 전달된다.
