# 브랜드 가이드라인

## 로고 사용 규정

로고는 지정된 여백 규칙을 지켜야 하며, 색 변형 없이 원본 컬러(딥블루 #1B3A5C)만
공식적으로 허용한다. 예외가 필요하면 마케팅팀 브랜드 담당자의 승인을 받는다.

## 톤앤매너

전문적이되 딱딱하지 않은 어조를 쓴다. 캠페인기획.md 에서 정한 이번 상반기 캠페인은
"실무자가 바로 이해하는 설명"을 핵심 원칙으로 삼는다.

## 적용 범위

이 가이드는 소셜미디어전략.md 가 다루는 모든 채널과 인쇄물, 웹사이트에 동일하게
적용된다. 외부 대행사와의 협업 시에도 이 문서를 기준 자료로 전달한다.

## 갱신 이력

브랜드 가이드는 연 1회 마케팅팀 정기 검토를 거쳐 갱신되며, 마지막 갱신은 올해 1월이다.
