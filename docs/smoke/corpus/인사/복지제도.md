# 2026년 복지제도 안내

## 개요

인사팀은 올해부터 선택적 복지 포인트 제도를 도입한다. 임직원은 매년 1월 200만원 상당의
포인트를 받아 정해진 항목 중 자유롭게 사용한다.

## 사용 가능 항목

- 자기계발(도서·강의·자격증): 한도 없음
- 건강관리(헬스장·건강검진 추가항목): 연 100만원
- 리프레시(휴가비 보조): 연 50만원
- 경조사 지원: 별도 규정에 따름

## 신규 입사자 처리

입사월 기준으로 포인트를 월할 계산해 지급한다. 신청 방법과 계정 활성화 절차는
온보딩.md 의 계정 발급 절차와 같은 사내 포털에서 처리되며, 입사 첫 2주 일정 동안 안내
메일이 자동 발송된다.

## 신청 방법

사내 포털 [복지몰] 메뉴에서 신청하고, 영수증은 신청일로부터 30일 이내에 업로드해야
정산된다. 인사팀 복지 담당자에게 문의는 사내 메신저로 받는다.
