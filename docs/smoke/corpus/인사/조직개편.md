# 2026년 하반기 조직개편안

## 배경

연구개발팀 인력이 채용계획.md 에 따라 상반기에 16명 충원되면서, 기존 단일 팀 구조로는
프로젝트별 책임 소재가 불명확해졌다는 지적이 나왔다. 이를 반영해 하반기 조직을 개편한다.

## 개편 내용

연구개발팀을 코어개발파트와 플랫폼개발파트로 분리한다. 코어개발파트는 스캔·추출·요약
파이프라인을, 플랫폼개발파트는 인덱싱·검색·향후 GUI 확장을 맡는다. 사업기획팀은 변경 없이
유지된다.

## 인력 배치

- 코어개발파트: 기존 인원 6명 + 신규 채용 8명
- 플랫폼개발파트: 기존 인원 4명 + 신규 채용 8명

신규 채용 인원의 배치는 채용계획.md 의 직군별 정원(백엔드 10명·데이터 6명)을 기준으로
확정하며, 최종 배치는 입사 후 4주 적응 기간을 거쳐 팀 리드 협의로 조정될 수 있다.

## 시행일

10월 1일부로 시행하며, 조직도와 보고 라인 변경은 시행일 1주일 전 공지한다.
