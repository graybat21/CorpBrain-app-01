# 로컬 API 서버 설계 초안

## 배경

아키텍처.md 가 밝힌 것처럼, CorpBrain의 코어는 CLI 외의 어댑터도 붙을 수 있도록
설계되어 있다. 이 문서는 향후 GUI가 붙을 때 코어를 호출할 로컬 API 서버의 초안을
정리한다. 아직 구현 시점은 정해지지 않았다.

## 원칙

API 서버는 127.0.0.1에만 바인딩하며 외부 네트워크에 노출하지 않는다. 인증은 로컬
프로세스 간 통신이라는 전제 하에 최소화하되, 향후 필요하면 로컬 토큰 방식을 추가한다.
서버 계층은 코어 함수를 그대로 호출하는 얇은 어댑터로 두고, 비즈니스 로직을 옮겨오지
않는다.

## 예상 엔드포인트

- `GET /status` — Doctor 진단 결과
- `POST /scan` — 스캔 시작, 진행상태는 서버-전송-이벤트(SSE)로 스트리밍
- `GET /graph/stats` — 그래프 통계 조회
- `GET /search` — 하이브리드 검색 결과 조회

## 남은 결정

프레임워크 선택(FastAPI 등)과 SSE 브리지 구현 방식은 착수 시점에 별도로 정한다.
연구개발팀은 이 문서를 참고자료로만 두고, 실제 착수 여부는 로드맵 논의를 따른다.
