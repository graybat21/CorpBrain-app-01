## :dart: Summary
- 기능명: [FR-013] 증분 재실행 정책
- 목적: 원문 mtime이 기존 위키보다 최신일 때만 재생성하고, `--force`면 mtime 무관 강제 재생성한다.

## :white_check_mark: Task Breakdown (실행 계획)
- [ ] `corpbrain/core/rerun.py`에 `should_regenerate(source_path, out_path, force: bool = False) -> bool`를 구현한다.
- [ ] `force=True`면 mtime 무관 항상 `True`를 반환한다.
- [ ] 대상 위키(`out_path`)가 존재하지 않으면 `True`(최초 생성)를 반환한다.
- [ ] 위키가 존재하면 원문 mtime과 기존 위키 mtime을 비교해 원문이 더 **최신일 때만** `True`, 아니면 `False`(스킵)를 반환한다.
- [ ] 스킵된 파일은 산출물을 만들지 않으며, 종료 요약의 스킵 리포트에 '최신 아님(up-to-date)' 사유로 보고되도록 상위 파이프라인/리포트(FR-015·FR-016)에 신호를 전달한다.
- [ ] `out_path`는 FR-012의 경로 미러링 규칙으로 산정한 위키 경로를 사용한다.
- [ ] 단위테스트: (a) 위키 없음→True, (b) 원문 mtime > 위키 mtime→True, (c) 원문 mtime ≤ 위키 mtime→False, (d) `force=True`→항상 True를 검증한다.

## :test_tube: Acceptance Criteria (BDD/GWT)
Scenario 1: 변경 없는 파일은 스킵
- Given: 원문 mtime이 기존 위키 mtime보다 최신이 아니고 `--force`가 지정되지 않음
- When: `should_regenerate(source_path, out_path, force=False)`를 평가한다
- Then: `False`를 반환하여 재생성하지 않고 스킵(사유: 최신 아님)으로 보고한다

Scenario 2: --force로 강제 재생성
- Given: 원문 mtime이 기존 위키보다 오래되었더라도 `--force`가 지정됨
- When: `should_regenerate(source_path, out_path, force=True)`를 평가한다
- Then: mtime과 무관하게 `True`를 반환하여 강제 재생성한다

## :gear: Technical & Non-Functional Constraints
- 보안: 파일 메타데이터(mtime) 비교만 수행하며 네트워크 호출 없음.
- 성능/안정성: 불필요한 LLM 호출을 피하기 위해 재생성 판단은 요약/렌더 이전 단계에서 수행한다(변경 없는 파일에 대한 재요약 방지). 스킵은 부분 성공으로 정상 보고한다.
