## :white_check_mark: Task Breakdown (실행 계획)
- [ ] 리포지토리 루트에 `pyproject.toml`을 추가하고 `[project]`에 `requires-python = ">=3.12,<3.13"`을 명시한다.
- [ ] `[project.scripts]`에 `corpbrain = "corpbrain.cli:main"` 콘솔 엔트리를 등록한다 (CLI 어댑터 진입점, 구현은 후속 FR).
- [ ] 리포지토리 루트에 `.python-version` 파일을 추가하고 `3.12`를 명시한다.
- [ ] `corpbrain/__init__.py`를 생성해 패키지를 초기화하고, `main`이 import 가능한 최소 `corpbrain/cli.py` 스텁을 둔다 (인자 파싱·로직은 후속 FR).
- [ ] 빌드 백엔드(예: `setuptools` 또는 `hatchling`)를 `[build-system]`에 지정해 패키지가 editable 설치 가능하도록 한다.
- [ ] `pip install -e .` 후 `corpbrain` 명령이 셸에서 인식되는지 확인한다.

## :test_tube: Acceptance Criteria (BDD/GWT)
Scenario 1: Python 3.12 환경에서 콘솔 엔트리 설치
- Given: Python 3.12 인터프리터가 활성화된 환경
- When: 리포지토리 루트에서 `pip install -e .`를 실행한다
- Then: 설치가 성공하고 `corpbrain` 콘솔 명령이 PATH에 등록되어 실행 가능하다.

Scenario 2: 런타임 버전 고정 위반
- Given: Python 3.13 인터프리터가 활성화된 환경
- When: `pip install -e .`를 실행한다
- Then: `requires-python = ">=3.12,<3.13"` 제약으로 설치가 거부된다.
