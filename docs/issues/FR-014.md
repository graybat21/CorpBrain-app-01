## :dart: Summary

## :white_check_mark: Task Breakdown (실행 계획)
- [ ] `corpbrain/cli.py`에 argparse(또는 동등) 기반 `scan` 서브커맨드를 정의한다. 위치 인자 `folder` 1개.
- [ ] 플래그를 스펙 §4.1 기본값 그대로 등록한다:
  - [ ] `--out DIR` (기본 `./corpbrain_wiki`)
  - [ ] `--model NAME` (기본 `qwen2.5:7b-instruct`, 환경변수 `CORPBRAIN_MODEL`로도 지정 가능)
  - [ ] `--max N` (기본 `50`)
  - [ ] `--max-chars N` (기본 `12000`)
  - [ ] `--ollama-url URL` (기본 `http://127.0.0.1:11434`)
  - [ ] `--force` (mtime 무관 강제 재생성, store_true)
- [ ] `--model` 우선순위 확정: 명시적 `--model` > 환경변수 `CORPBRAIN_MODEL` > 기본값. (명시 플래그가 환경변수를 이긴다)
- [ ] 파싱 결과를 코어가 받는 설정 데이터클래스(예: `ScanConfig`)로 매핑하고 코어 파이프라인 진입 함수(FR-015 제공)를 호출한다. CLI는 인자 파싱·로그·종료코드 매핑 외 비즈니스 로직을 포함하지 않는다(§4.5).
- [ ] 콘솔 엔트리(`corpbrain`, FR-001 제공)에서 이 파서가 디스패치되도록 연결한다.

## :test_tube: Acceptance Criteria (BDD/GWT)
Scenario 1: 기본값으로 파싱
- Given: 사용자가 `corpbrain scan ./inbox`만 입력한다.
- When: CLI 파서가 인자를 처리한다.
- Then: `folder=./inbox`, `out=./corpbrain_wiki`, `model=qwen2.5:7b-instruct`, `max=50`, `max_chars=12000`, `ollama_url=http://127.0.0.1:11434`, `force=False`인 설정 객체가 생성되어 코어 진입 함수로 전달된다.

Scenario 2: 환경변수 대비 명시 플래그 우선
- Given: 환경변수 `CORPBRAIN_MODEL=envmodel`이 설정된 상태다.
- When: 사용자가 `corpbrain scan ./inbox --model flagmodel`을 실행한다.
- Then: 설정 객체의 `model`은 `flagmodel`이다(명시 플래그가 환경변수를 이긴다). `--model` 없이 실행하면 `envmodel`이 사용된다.

## :gear: Technical & Non-Functional Constraints
- 보안: 외부 통신은 `--ollama-url`(기본 localhost)로만 향한다. CLI 계층에서 다른 네트워크 호출·텔레메트리를 발생시키지 않는다(§1, §4.5).
- 성능/안정성: CLI는 얇은 어댑터로 유지한다(§4.5). 파싱·검증·디스패치만 담당하고 스캔/추출/요약/렌더 로직은 코어에 위임한다. 런타임은 Python 3.12 고정(§4.1).
