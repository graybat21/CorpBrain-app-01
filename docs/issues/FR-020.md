## :test_tube: Acceptance Criteria (BDD/GWT)
Scenario 1: 실제 모델로 위키 생성 성공
- Given: 로컬 Ollama가 기동되어 있고 기본 모델이 준비된 상태와 소형 실샘플 폴더
- When: `corpbrain scan <sample> --out <tmp>` 를 실제 모델로 1회 실행한다
- Then: 지원 파일마다 한국어로 채워진 `<원본이름>.md`(front-matter 4키·6섹션)가 생성되고, 종료 요약에 처리/스킵 건수와 출력 경로가 표시되며 종료 코드는 0이다

Scenario 2: Ollama 미기동 시 선행 조건 실패
- Given: 로컬 Ollama가 기동되어 있지 않은 상태
- When: 동일 명령을 실행한다
- Then: 설치를 시도하지 않고 비-0 종료 코드로 실패하며, 사유가 stderr 로그에 남는다

## :gear: Technical & Non-Functional Constraints
- 보안: 실제 실행 역시 외부 통신은 `--ollama-url`(localhost) 로컬 Ollama 호출뿐이며 그 외 네트워크·텔레메트리 0이다. Ollama는 탐지만 하고 설치·프로비저닝하지 않는다.
- 성능/안정성: LLM 레이턴시에 대한 SLA는 없다(수동 스모크). 자동화 CI 게이트가 아닌 릴리즈 전 최종 수동 확인 단계이며, 실행 절차와 결과는 반드시 문서로 기록해 재현 가능해야 한다.
