- 기능명: [FR-004] 재귀 파일 스캐너 + 포맷 필터(.docx/.txt/.md)

## :white_check_mark: Task Breakdown (실행 계획)
- [ ] `corpbrain/core/scanner.py`에 재귀 스캐너 함수 `scan_folder(root: Path) -> Iterator[Path]` 구현 — `os.walk` 또는 `Path.rglob`로 하위폴더까지 순회.
- [ ] 지원 확장자 집합 상수 정의: `SUPPORTED_EXTENSIONS = {".docx", ".txt", ".md"}` (대소문자 무시 비교).
- [ ] 포맷 필터 함수 `is_supported(path: Path) -> bool` 구현 — 미지원 확장자는 False.
- [ ] 스캐너는 입력 하위구조를 보존할 수 있도록 각 파일의 `root` 기준 상대경로를 계산 가능한 형태(절대경로+root)로 반환한다(후속 미러링 출력 FR-012의 기반).
- [ ] 미지원 확장자 파일은 결과에서 제외하되, 사유(`unsupported_extension`)와 경로를 기록해 스킵 리포트로 넘길 수 있게 반환 구조에 포함(FR-005 가드레일과 연결).
- [ ] 스캐너는 파일을 통째로 열지 않고 경로 목록만 다룬다(텍스트 추출은 FR-006/FR-007 담당).
- [ ] 코어 API 단독 호출만으로 스캔이 end-to-end 동작함을 확인(CLI 의존 없음, §4.5).

## :test_tube: Acceptance Criteria (BDD/GWT)
Scenario 1: 지원 포맷만 재귀 선별
- Given: 하위폴더와 정상 `.docx/.txt/.md` 파일, 그리고 미지원 확장자(예: `.pdf`, `.jpg`) 파일이 섞인 픽스처 폴더가 있다.
- When: `scan_folder(fixture)`를 호출한다.
- Then: 반환된 처리 대상 목록은 하위폴더 포함 모든 `.docx/.txt/.md` 파일을 담고, 미지원 확장자 파일은 처리 대상에서 제외된다.

Scenario 2: 미지원 확장자 스킵 분류
- Given: 픽스처에 `.pdf` 등 미지원 확장자 파일이 있다.
- When: 스캐너가 해당 파일을 만난다.
- Then: 처리 대상이 아니라 사유 `unsupported_extension`으로 스킵 리포트에 분류되고 로그로 남는다.

## :gear: Technical & Non-Functional Constraints
- 보안: 파일시스템 순회만 수행하며 외부 네트워크 호출은 전혀 하지 않는다(외부 통신은 이후 단일 관문 경유 Ollama뿐).
- 성능/안정성: 파일 내용을 메모리에 통째로 올리지 않고 경로만 스트리밍/이터레이터로 다룬다. 확장자 비교는 대소문자 무시. 코어 모듈로 분리해 CLI 없이 함수 호출로 재사용 가능해야 한다(§4.5).
