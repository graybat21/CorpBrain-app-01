- 같은 원문을 가리키는 위키를 경고한다 — 스펙 §5에 추가, 커밋 `a74d220`
- 링크 규칙 문구를 구현에 맞춰 정정 — 스펙 §4.5, 커밋 `a74d220`

**확인하고 그대로 둔 것**

- `upsert_facts` 즉시 커밋 (문서마다 fsync 1회)을 유지한다. 재료를 `replace_graph`의
  트랜잭션에 묶으면 재빌드 실패 시 `doc_facts`가 함께 롤백되어, 위키는 이미 생성됐는데
  엔티티만 사라진다. 그 상태는 mtime 때문에 재요약되지 않아 `--force`로 LLM 호출 전량을
  다시 지불해야 회복된다 — 일시적 디스크 오류가 비용의 영구 손실로 번지는 셈이다.
  커밋 비용은 같은 문서에서 이미 도는 LLM 호출(수 초)에 묻히는 수준이고, 재실행에서는
  `upsert_facts`가 호출되지 않아 커밋도 0회다. `--max`를 크게 올려 수천 문서를 도는 사용
  방식이 생기면 «재료 전용 트랜잭션»(커밋 2회, 계약 메서드 10개)을 다시 검토한다.
- `entities` 선택 필드의 안전망이 수동 스모크(실행 H)뿐인 구조를 유지한다. 스텁이 값을
  정하므로 자동 테스트는 모델이 이 필드를 늘 비워 보내도 통과한다 — 실제 모델의 충실도는
  스텁이 원리적으로 증명할 수 없는 영역이라 스모크가 맡는 것이 맞다.
