## 1. 위상 관계(Hierarchy) 분석 및 재설계

### 1.1 기존 위상 관계의 문제점 (Flat / Inverted Hierarchy)
```
[기존 구조]
├── 전역 메뉴 (대시보드, 스캔, 지식그래프, 위키, 검색, 설정)  <-- 프로젝트 상위에 위치하여 혼란 유발
└── Projects (프로젝트 목록)                                  <-- 하위 목록으로 취급되어 소속감 불명확
```
- 프로젝트를 선택하더라도 상단 메뉴가 전역 메뉴처럼 보여, 사용자가 "이 대시보드가 전체 시스템 대시보드인지, 특정 프로젝트 대시보드인지" 구분이 어려웠습니다.

### 1.2 개선된 위상 관계 (Project-Scoped Architecture)
```
[개선된 위상 관계]
├── 1. 최상위: 현재 활성 프로젝트 (Active Workspace Header)
│      └── [ 📁 CorpBrain-app-01 / feat/v0.5-cloud-opt-in ▾ ]
│
├── 2. 프로젝트 내부 스코프 메뉴 (Project Workspace Features)
│      ├── 📊 프로젝트 대시보드 (Project Dashboard)
│      ├── 🚀 플랜 & 스캔 (Plan & Scan)
│      ├── 🕸️ 지식그래프 (Knowledge Graph)
│      ├── 📖 위키 탐색기 (Wiki Explorer)
│      └── 🔍 프로젝트 지식 검색 (Search)
│
├── 3. 워크스페이스 전환기 (Switch Workspace / Projects)
│      ├── 📁 CorpBrain-app (main)
│      ├── 📁 HR-KnowledgeBase (main)
│      ├── 📁 Legal-Compliance-2026 (v0.4-vector)
│      └── ➕ 새 로컬 프로젝트 추가...
│
└── 4. 글로벌 시스템 영역 (Global Scope)
       ├── ⚙️ 시스템 보안 및 설정 (Settings & Consent)
       └── ● 100% Local Guard Status (127.0.0.1:11434)
```

## 2. 세부 UI 컴포넌트 사양

### 2.1 사이드바 상단: Active Workspace Header
- 현재 선택된 프로젝트명(`CorpBrain-app-01`)과 활성 브랜치(`feat/v0.5-cloud-opt-in`)를 강조된 카드 형태로 최상단에 배치.
- 우측에 빠른 프로젝트 전환 드롭다운 화살표(▾) 및 스캔 상태 태그(`42 docs`) 표시.

### 2.2 사이드바 중단: Project Scoped Navigation
- 활성 프로젝트 내부의 5대 핵심 기능을 소속감 있게 배치:
  - `📊 대시보드`: 해당 프로젝트의 위키 수, 엔티티 수, 지식그래프 요약
  - `🚀 플랜 & 스캔`: 해당 프로젝트 폴더 대상 계량 및 스캔 실행
  - `🕸️ 지식그래프`: 해당 프로젝트의 노드/엣지 연결망 캔버스
  - `📖 위키 탐색기`: 해당 프로젝트 폴더 트리 및 마크다운 리더
  - `🔍 지식 검색`: 해당 프로젝트 벡터/시맨틱 검색
- 각 메뉴 우측에 **해당 프로젝트 전용 데이터 카운트 배지**를 표기하여 소속감을 극대화.

### 2.3 사이드바 하단: Switch Project (프로젝트 목록 & 추가)
- 다른 프로젝트로 즉시 전환할 수 있는 직관적인 리스트.
- 클릭 시 즉시 1번과 2번 영역이 해당 프로젝트로 재구성됨.

### 2.4 최하단 고정: Global Settings & Security
- 프로젝트와 무관한 시스템 전역 설정(클라우드 동의, PII 규칙, 하드웨어 진단)을 최하단에 분리 고정.
