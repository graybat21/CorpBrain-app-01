# CorpBrain 멀티 워크스페이스(프로젝트/폴더) GUI 설계 및 상세 명세서

- **문서 번호**: 03
- **작성일**: 2026-08-21
- **작성자**: AI 동료 다온 (수신: 회비서)
- **상태**: 확정 및 프로토타입 반영 완료
- **목적**: 사용자가 여러 프로젝트/폴더 단위로 지식 베이스를 독립적으로 관리하고 원클릭으로 전환할 수 있도록 사이드바에 프로젝트 계층 네비게이션을 설계하고 GUI에 반영함.

---

## 1. 문제 정의 및 개선 방향

### 1.1 기존 문제점
- 기존 GUI는 단일 전역 지식 베이스(폴더 1개)를 기준으로 화면이 구성되어 있어, 회비서님이 여러 프로젝트 폴더(예: `CorpBrain-app-01`, `HR-Docs`, `R&D-Specs` 등)를 오가며 작업할 때 폴더 간 구분이 어렵고 매번 입력 경로를 재설정해야 하는 불편이 있었습니다.

### 1.2 개선 방향 (첨부 이미지 참조)
- **좌측 사이드바에 전용 Projects(워크스페이스) 섹션 도입**:
  - 프로젝트명, 활성 브랜치(`main`, `feat/v0.5-cloud-opt-in` 등), 기본([기본]) 배지, 최근 스캔/작업 태그를 한눈에 식별 가능한 카드로 배치.
  - 상단에 **프로젝트 추가(+) / 폴더 열기(📁) / 필터(⚙️)** 액션 툴바 배치.
  - 프로젝트 카드를 클릭하면 **대시보드 통계, 스캔 기본 경로, 위키 탐색기 트리, 지식그래프 캔버스가 해당 프로젝트 전용 컨텍스트로 실시간 전환**.

## 3. 프로젝트 전환 인터랙션 흐름

1. **프로젝트 선택 (Click)**:
   - 사용자가 사이드바의 `CorpBrain-app-01` 또는 `HR-KnowledgeBase` 등을 클릭.
2. **컨텍스트 자동 동기화**:
   - **Header**: 상단 타이틀 옆에 현재 활성 프로젝트 칩(`📁 CorpBrain-app-01 / feat/v0.5-cloud-opt-in`) 갱신.
   - **Scan Hub**: 스캔 대상 폴더(`input_folder`) 및 위키 출력 폴더(`out_dir`)가 해당 프로젝트 경로로 자동 채워짐.
   - **Dashboard**: 해당 프로젝트의 위키 문서 수, 엔티티 수, 지식그래프 노드/엣지 통계로 즉시 리프레시.
   - **Wiki Reader**: 해당 프로젝트의 폴더 트리 및 마크다운 파일 목록으로 전환.
   - **Knowledge Graph**: 해당 프로젝트의 지식그래프 토폴로지(노드 및 연결망)로 캔버스 재구성.
3. **새 프로젝트 추가(+) 모달 / 인풋**:
   - 로컬의 새 폴더를 스캔 대상 워크스페이스로 즉시 등록 가능.
