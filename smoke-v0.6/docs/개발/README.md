# 개발 문서 폴더 안내

이 파일(README.md)은 개발 폴더에 어떤 문서가 있고 무엇을 먼저 읽어야 하는지 안내한다.
연구개발팀에 새로 합류했다면 여기서 시작한다.

## 읽는 순서

1. **아키텍처.md** — 코어와 어댑터를 어떻게 나눴는지, 처리 흐름이 어떻게 되는지
2. **벡터설계.md** — 임베딩과 인덱스 저장 방식

## 문서를 추가할 때

- 파일명은 한국어 명사로 짓는다. 영문 약어를 파일명에 쓰지 않는다.
- 첫 줄은 `#` 제목 하나로 시작한다.
- 다른 문서를 가리킬 때는 파일명을 그대로 적는다. 상대 경로를 쓰지 않는다.
- 결정의 근거를 함께 적는다. 무엇을 했는지보다 왜 그렇게 했는지가 나중에 더 필요하다.

## 문서를 고칠 때

이미 있는 문서의 결론을 바꿀 때는 바뀐 이유를 본문에 남긴다. 이력을 커밋 메시지에만
두면 문서만 읽는 사람이 맥락을 잃는다.
